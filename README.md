# IELTS Speaking Bot

Telegram-бот для автоматической оценки устной речи по шкале IELTS.
Студент отправляет голосовое сообщение на английском — бот даёт развёрнутую оценку и советы.

---

## Как это работает

```
Студент отправляет голосовое (OGG)
            ↓
    FFmpeg конвертирует в MP3 (16kHz, mono)
            ↓
    OpenAI Whisper-1 → текстовый транскрипт
            ↓
    GPT-4o анализирует по критериям IELTS
            ↓
    Бот отвечает подробной оценкой
```

---

## Что получает студент в ответ

- **Band-баллы** по 4 критериям:
  - Fluency & Coherence (Беглость и связность)
  - Lexical Resource (Словарный запас)
  - Grammatical Range & Accuracy (Грамматика)
  - Pronunciation (Произношение — оценка по транскрипту)
- **Итоговый балл** (среднее, округлённое до 0.5)
- **Конкретные ошибки** с исправлениями
- **Улучшенный вариант** ответа (Band 7+)
- **Советы** по улучшению

## Переменные окружения

Создай файл `.env` на сервере (по шаблону `.env.example`):

```env
BOT_TOKEN=8716627566:AAH...         # Токен бота от @BotFather
MY_CHAT_ID=266889430                # Твой Telegram ID
OPENAI_API_KEY=sk-...               # Ключ OpenAI API
VIDEO_SAVING_PATH=/opt/ielts-bot/savings  # Папка для аудио
```

> **Важно:** файл `.env` никогда не коммитится в git.

## Локальный запуск (для разработки)

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd ielts-bot

# 2. Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Создать .env файл
cp .env.example .env
# Заполнить .env своими ключами

# 5. Убедиться, что ffmpeg установлен
ffmpeg -version

# 6. Запустить бота
python -m bot.bot
```
