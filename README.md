# IELTS Speaking Bot

Telegram-бот для автоматической оценки устной речи по шкале IELTS.
Студент отправляет голосовое сообщение на английском — бот даёт развёрнутую оценку и советы.

---

## Как это работает

```
Студент отправляет голосовое (OGG)
            ↓
    FFmpeg конвертирует в MP3 (16kHz, mono)
            ↓
    OpenAI Whisper-1 → текстовый транскрипт
            ↓
    GPT-4o анализирует по критериям IELTS
            ↓
    Бот отвечает подробной оценкой
```

---

## Что получает студент в ответ

- **Overview** — краткий общий разбор выступления
- **Grammar** — 3 наиболее частые грамматические ошибки с исправлениями (`❌ → ✅`)
- **Vocabulary** — 3 слова/коллокации, использованные некорректно, с заменами
- **Ideas** — как лучше раскрыть идеи и что добавить в следующий раз
- **Improved Version** — переработанный вариант ответа с исправленными ошибками

---

## Что получает учитель в ответ

Учительский отчёт компактнее и включает расширенный анализ для работы с учеником:

| Секция | Описание |
|---|---|
| **IELTS Scores** | Баллы по 4 критериям + итоговый, одна строка обоснования на каждый |
| **Authenticity Check** | Зачитал ли ученик с бумаги? Использовал ли ИИ для генерации? Вердикт + причина |
| **Top 3 Grammar Mistakes** | Три наиболее значимых грамматических ошибки с исправлением и правилом |
| **Top 10 Vocabulary Misuses** | Слова, использованные некорректно или неточно, с заменами для данного контекста |
| **Idea Development** | Насколько чётко сформулированы идеи, есть ли поддержка примерами, логика изложения |

│       ├── teacher.py      # Обработчик для учителей: расширенный анализ
│       └── group.py        # Модерация группы: мат, ссылки, флуд, дубли
├── chatgpt_api/
│   ├── __init__.py

├── .gitignore
├── requirements.txt        # Python-зависимости
├── ielts-bot.service       # systemd-юнит для автозапуска на сервере

## Переменные окружения

Создай файл `.env` на сервере (по шаблону `.env.example`):

```env
BOT_TOKEN=your_bot_token_here            # Токен бота от @BotFather
OPENAI_API_KEY=sk-...                    # Ключ OpenAI API
VIDEO_SAVING_PATH=/opt/ielts-bot/savings # Папка для аудио
GROUP_ID=-1001234567890                  # ID группы (учителя = admin группы)
```

> **Важно:** файл `.env` никогда не коммитится в git.

## Локальный запуск (для разработки)

### Linux / macOS

```bash
# 1. Клонировать репозиторий
# git создаёт папку autimation-for-english-teachers (имя репозитория)
git clone <repo-url>
cd autimation-for-english-teachers

# 2. Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Создать .env файл
cp .env.example .env
# Заполнить .env своими ключами

# 5. Убедиться, что ffmpeg установлен
ffmpeg -version

# 6. Запустить бота
python -m bot.bot
```

### Windows

> **Требование к версии Python: 3.11 или 3.12.**
> Python 3.13+ не поддерживается зависимостями (pydantic-core не имеет готовых сборок).
> Скачать нужную версию: [python.org/downloads](https://www.python.org/downloads/)

**1. Установить Python 3.11 или 3.12**

На странице загрузки выбрать версию **3.11.x** или **3.12.x** → при установке поставить галочку **"Add Python to PATH"**.

Проверить версию после установки:
```powershell
python --version
# Должно быть Python 3.11.x или 3.12.x
```

**2. Установить ffmpeg**

```powershell
winget install ffmpeg
```

После установки **перезапустить терминал**, затем проверить:

```powershell
where.exe ffmpeg
```

Должен вернуть путь к ffmpeg.exe.

**3. Перейти в папку репозитория**

После клонирования git создаёт папку с именем репозитория — `autimation-for-english-teachers`:

```powershell
cd autimation-for-english-teachers
```

Если репозиторий уже был скачан раньше, перейди в его корень (там где лежит `requirements.txt`).

**4. Создать виртуальное окружение** (из корня проекта)

```powershell
python -m venv venv
venv\Scripts\activate
```

> Важно: команды 4–7 выполнять **только из корня проекта** (там где `requirements.txt`), не заходя в `bot/` или другие подпапки.

**5. Установить зависимости**

```powershell
pip install -r requirements.txt
```

**6. Создать .env файл**

```powershell
copy .env.example .env
```

Открыть `.env` в редакторе и заполнить ключи. Для `VIDEO_SAVING_PATH` можно указать папку внутри проекта — она создастся автоматически:

```env
VIDEO_SAVING_PATH=savings
```

> `savings` — относительный путь, папка создаётся рядом с проектом. Работает если запускать бота из корня проекта.

**7. Запустить бота**

```powershell
python -m bot.bot
```
