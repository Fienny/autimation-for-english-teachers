# Руководство по тестированию

Как проверить весь функционал самостоятельно, без реальных учеников.

---

## 1. Подготовка

### 1.1 Создать тестовую группу

1. В Telegram: нажми **«Создать группу»** → назови, например, `IELTS Test Group`
2. Добавь своего бота в группу
3. Назначь бота администратором (иначе он не сможет удалять сообщения):
   **Управление группой → Администраторы → Добавить администратора → выбери бота**
   Нужные права: **«Удаление сообщений»**

### 1.2 Узнать ID группы

Добавь в группу бота `@userinfobot`, напиши `/start` — он покажет ID группы (число вида `-1009876543210`).
После этого можно удалить `@userinfobot` из группы.

### 1.3 Прописать GROUP_ID в .env

```
GROUP_ID=-1009876543210
```

Перезапусти бота после изменения `.env`.

## 2. Тестирование в личном чате

### Роль «чужой» (outsider)

1. Напиши боту в личку любое сообщение **до** вступления в группу (или с аккаунта, которого нет в группе)
2. **Ожидаемо:** «Доступ закрыт. Ты должен состоять в группе...»

### Роль «ученик» (student)

1. Вступи в тестовую группу со своего основного аккаунта (не как администратор)
2. Напиши боту в личку `/start`
3. **Ожидаемо:** приветствие для ученика
4. Запиши и отправь голосовое сообщение на английском (достаточно 10–20 секунд)
5. **Ожидаемо:** «Транскрибирую...» → «Оцениваю...» → развёрнутая оценка IELTS

### Роль «учитель» (teacher)

1. В настройках тестовой группы назначь свой аккаунт администратором
2. Напиши боту в личку `/start`
3. **Ожидаемо:** приветствие учителя со списком всех функций анализа
4. Отправь голосовое ответа ученика (можно своё — зачитай любой абзац на английском)
5. **Ожидаемо:** «Транскрибирую...» → «Анализирую...» → полный отчёт (см. раздел 2а ниже)

> **Совет:** Проще всего переключать роли, используя второй аккаунт Telegram
> (или аккаунт на второй SIM-карте / в Telegram Web) — один как обычный участник,
> другой как администратор.

## 2а. Тестирование расширенного анализа для учителя

Учительский отчёт всегда содержит **5 секций**. Ниже — как проверить каждую из них.

### Сценарий 1 — «слабый ученик»

Запиши голосовое: прочитай вслух, намеренно допуская ошибки:

```
Yesterday I go to shop and buyed many things. I very like shopping
because is fun and good. I thinks that shopping help us to getting
what we need every day. For example I need to buy a food and clothes
and other necessities.
```

**Что проверяем в отчёте:**

| Секция | Что должно быть |
|---|---|
| IELTS Scores | Низкие баллы (5.0–6.0), краткое обоснование |
| Authenticity Check | Likely read from notes — монотонный темп без пауз |
| Top 3 Grammar Mistakes | `go → went`, `buyed → bought`, `I thinks → I think` |
| Top 10 Vocabulary Misuses | `go to shop → go to the shop / go shopping`, `a food → food` и т.д. |
| Idea Development | Weak — идеи не раскрыты, нет примеров |

---

### Сценарий 2 — «сильный ученик»

Запиши голосовое: импровизируй свободно на тему, например:

```
Talk about a memorable journey you have taken.
```

Говори свободно, с паузами, используй разнообразную лексику.

**Что проверяем в отчёте:**

| Секция | Что должно быть |
|---|---|
| IELTS Scores | Высокие баллы (7.0–8.5) |
| Authenticity Check | No — естественные паузы, самокоррекция, разговорный стиль |
| Top 3 Grammar Mistakes | Мелкие ошибки, если есть |
| Top 10 Vocabulary Misuses | Минимум, или указания на более точные слова |
| Idea Development | Strong / Adequate |

---

### Сценарий 3 — проверка на ИИ-генерацию

Возьми текст, сгенерированный ChatGPT (например, попроси его написать ответ на IELTS Part 2), зачитай его монотонно в голосовое.

**Ожидаемо в Authenticity Check:**
- `AI-generated text? — Likely / Yes`
- Причина: overly formal register, suspiciously perfect grammar, unusual vocabulary for the level

## 3. Тестирование модерации группы

Все тесты проводятся **в тестовой группе**.
Сначала убедись, что твой аккаунт **не является администратором** группы —
иначе модерация не сработает (администраторы не проверяются).

---

### 3.1 Мат — русский

Напиши в группе любое слово из запрещённого списка (например, слово из 3 букв на букву «х»).

**Ожидаемо:**
- Сообщение удалено
- Бот написал: `⚠️ [Имя], твоё сообщение удалено. Причина: нецензурная лексика.`

---

### 3.2 Мат — английский

Напиши в группе, например: `what the fuck`

**Ожидаемо:** то же, что в п. 3.1

---

### 3.3 Ссылки

Попробуй отправить:
- `https://example.com`
- `www.google.com`
- `t.me/someuser`

**Ожидаемо:**
- Сообщение удалено
- Бот написал: `⚠️ [Имя], твоё сообщение удалено. Причина: ссылки запрещены.`

---

### 3.4 Флуд (>5 сообщений за 10 секунд)

Отправь 6 любых сообщений подряд как можно быстрее (скопируй и отправляй одно за другим):

```
1
2
3
4
5
6
```

**Ожидаемо:** 6-е сообщение удалено, предупреждение о флуде.

> Через 10 секунд счётчик сбрасывается — можешь снова писать нормально.

---

### 3.5 Дубли (одинаковый текст 2 раза подряд)

1. Напиши: `Hello everyone`
2. Напиши снова: `Hello everyone`

**Ожидаемо:** второе сообщение удалено, предупреждение о повторе.

---

### 3.6 Администратор не модерируется

1. Назначь свой аккаунт администратором группы
2. Повтори любой из тестов выше (ссылка, мат, флуд, дубль)

**Ожидаемо:** сообщения **не** удаляются — администраторы освобождены от модерации.

## 4. Быстрая сводка

| Функционал | Где тестировать | Что отправить |
|---|---|---|
| Outsider — отказ | Личный чат | Любое сообщение (без членства в группе) |
| Student — IELTS | Личный чат (участник) | Голосовое на английском |
| Teacher — полный отчёт | Личный чат (admin) | Голосовое ответа ученика |
| Teacher — слабый ученик | Личный чат (admin) | Текст со сценария 1 |
| Teacher — сильный ученик | Личный чат (admin) | Свободная речь на тему |
| Teacher — детект ИИ | Личный чат (admin) | Зачитанный ChatGPT-текст |
| Мат (рус) | Группа (не admin) | Матерное слово |
| Мат (eng) | Группа (не admin) | `fuck` / `shit` и т.п. |
| Ссылка | Группа (не admin) | `https://...` или `t.me/...` |
| Флуд | Группа (не admin) | 6 сообщений за 10 сек |
| Дубль | Группа (не admin) | Один текст 2 раза подряд |
| Admin-исключение | Группа (admin) | Любое из нарушений выше |
